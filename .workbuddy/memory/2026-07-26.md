- 扩展位于 `/etc/supd/extensions/auto-create-users/`（全局扩展，supd PID1 以 root 运行）。
- **根因**：188 实际部署的 `meta.yaml` 是 **`enabled: false`**（代码模板 `init_examples.go` 里是 `enabled: true`、triggers `supd_lifecycle: pre_start`；188 实际改成 `enabled: false` + `post_ready` + 描述"默认禁用"）→ 被禁用，supd 启动不自动跑 → 用户不自动创建。
