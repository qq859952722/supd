## 关键技术点

- **NSpid 精确映射**：`/proc/<host-pid>/status` 的 `NSpid:` 行最后一项是最内层 namespace PID，可用于精确匹配容器内进程
- **CPU 批量采样**：降级路径先收集整棵树 host PID，批量 `getProcess` 预热基线，统一 `sleep 200ms` 一次，避免逐进程等待
- **curl 流式落盘**：`curl --fail --location --silent --show-error --output <dest>.part` 直接写文件，成功后 `tjs.rename` 原子替换，不经过 JS 内存缓冲
- **按需依赖检查**：curl 仅下载时需要，tar/unzip 仅 WASM fallback 时需要，uname 仅架构探测最后 fallback 时需要；不启动时统一检查
- **nil 防御最小化**：`buildStopConfigs` 返回已初始化空 map，下游 `ShutdownCoordinator` 对缺失配置回退默认 10s/60s
