## 三、测试用例（详细）

### A. 静态 / 单元

### B. 扩展运行测试 — transmission-updater（核心）
- **B1 check-update（未安装）**：
  `sudo SUPD_ACTION=check-update SUPD_SERVICE_DIR=/tmp/test-workdir/services/transmission SUPD_SERVICE=transmission /home/qq/tjs .../transmission-updater/run.js`
  预期：输出"二进制未安装" + 成功获取 latest 版本（验证 GitHub 访问 + JSON 解析 + 版本归一化执行路径），**不崩溃**。
- **B2 install-update（核心集成）**：
  预期依次验证：
  1. runCmd 并发读两路流 → tar/unzip 大量 stderr 不造成**死锁**（P0#1 回归验证）
  2. findFile 精确匹配 `transmission-daemon` 二进制（P1#3 验证）
  3. chown 校验：sudo 下 exitCode=0 成功；若以非 root 跑应打印 warning 而非静默失败（P1#4 验证）
  4. 下载 + 解压 + 复制完成，二进制存在且可执行（`ls -l .../transmission-daemon`）
- **B3 版本比较回归（P0#2）**：
  install 后再次 `check-update`，current 与 latest 解析一致 → 输出"已是最新版本"（不再误报"发现新版本"）。
  边界：tag 为 `v4.1.3` → latest 解析 `4.1.3`；本地 `--version` 解析 `4.1.3` → 相等。

### C. 服务运行测试 — supd 监督 transmission
- **C1** `sudo SUPD_LOG_DIR=/tmp/supd-logs /tmp/supd --workdir /tmp/test-workdir run --listen :7979 &` 启动；验证服务被加载且状态合理（初始 down，因二进制待安装）。

  → 验证 env 注入（SUPD_SERVICE_DIR/SUPD_ACTION/run_as=root）全链路 + 安装 + 重启服务。
- **C4** 服务就绪：readiness `tcp_check 9091` 通过 → 状态 `up`。

- **C6** `GET /api/services/transmission/processes` → 主进程 + 子进程、UID/GID 展示、命令、状态合理。
