# 扩展概述

`scheduled-ping` 版本 `1.0.0`，是每分钟输出一次时间戳的 Bash 定时扩展示例。

# 触发方式与 Actions

`on_schedule` 使用 cron `*/1 * * * *` 每分钟触发 `ping` action；未显式配置并发策略。

# 运行逻辑

入口脚本调用 `date`，向日志输出一行带当前时间的 ping 信息。

# 配置与环境变量

无需自定义环境变量；运行时 action 为 `ping`。

# 开发与外部资源

依赖 Bash 和 `date`；无上游项目或下载链接。

# 部署与特别注意事项

作为全局扩展示例时入口为扩展目录下的 `run.sh`；复制后应保持目录、入口路径和配置一致。

# 验证与故障排查

等待 cron 触发并查看扩展日志中的 `[scheduled-ping] ping at`；无输出时核对扩展是否启用、cron 表达式和系统时间。
