# 扩展概述

`stats-report-ext` 版本 `1.0.0`，演示定时和手动生成服务状态统计报告。

# 触发方式与 Actions

支持 `on_demand`，并通过 cron `*/30 * * * *` 每 30 分钟触发 `report`；并发策略为 `replace`。

# 运行逻辑

脚本请求目标服务根路径，收集系统运行时长、内存和磁盘信息，再结合 SUPD 服务上下文输出进度、报告和结果。服务不可达时报告使用系统与上下文信息并标记警告。

# 配置与环境变量

`SERVICE_PORT` 默认 `8080`；读取 `SUPD_ACTION`、`SUPD_SERVICE`、`SUPD_SERVICE_PID`、`SUPD_TRIGGER_TIME` 和 `SUPD_TRIGGER_SOURCE`。

# 开发与外部资源

依赖 Bash、`curl`、`uptime`、`free`、`df`、`awk` 和 `date`；无上游项目或下载链接。

# 部署与特别注意事项

需关联具体服务上下文时应部署为服务级扩展。统计是执行时的系统级快照，不是持久化监控数据；脚本不会写报告文件。

# 验证与故障排查

手动触发 `report` 并查看进度及最终结果，再确认定时触发日志。信息缺失时核对环境上下文、目标端口和系统命令是否可用。
